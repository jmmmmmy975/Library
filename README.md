# Library 0.3.0

包含柔和主题过渡、按压回弹、按需文件预览和应用图标主页，以及源代码子分类导航。图片/视频默认信息卡片，Ctrl+3进入较大的封面画廊。保留平滑滚动、双击打开、内部焦点提示、圆长滑块与最大化边界修复。

面向 Windows 的私人数字图书馆。分类告诉你文件是什么，真实路径保留你对文件的控制。

## 启动

Windows 10/11 x64：解压整个文件夹，双击 `Library.exe`。独立版已包含.NET运行时，不需要安装SDK或管理员权限。请保留同目录的DLL和资源文件。

默认后台索引桌面、文档、下载、图片、视频、音乐，以及开始菜单快捷方式。目录来自Windows当前环境；不扫描整个磁盘、Windows、Program Files或整个AppData。首次索引时可以继续导航。设置里可以添加**引用**目录、停用位置、重扫或取消；停用保留旧索引。所有文件默认留在原处。

索引数据库不可用时会说明错误，由你选择示例模式或退出；不会把示例馆藏当成真实文件。示例可用 `Library.exe --data=sample` 启动。

## 日常使用

- 大厅进入分类；Ctrl+1列表、Ctrl+2信息卡片，图片/视频中Ctrl+3为大预览封面画廊（仅名称、完整画面，和卡片的类型/大小/时间有区别）。图片/视频默认卡片；应用程序是图标/名称主页，单击选择、双击或「启动」打开。F6定位文件，方向键与PageUp/PageDown浏览。
- 单击选中文件，双击/Enter使用Windows默认关联。用「详情」或Ctrl+D展开信息面板；单击时不自动挤动网格，保证双击命中稳定。文件列表中F2重命名，Delete先显示回收站确认；输入框不拦截编辑按键。详情提供真实路径及明确触发的文件操作。
- 列表/网格/大厅滚轮按像素平滑过渡，支持小幅增量和反向；键盘或鼠标按下会停止惯性。Windows关闭客户端动画时直接定位，不强行动画。Ctrl+End及滚动条快速跳转保持即时。
- 文件菜单「分类与标签」管理用户分类/标签；选中文件的详情入口可勾选多个分类和标签。拖入用户分类只增加引用，文件不会移动。内置类型分类为派生只读视图。
- Ctrl+F筛选当前分类；Ctrl+Shift+F搜索全库。例：`*.pdf size:>1MB`、`category:大学 tag:重要`、`path:"D:\Projects" after:2026-01-01`。搜索窗口「语法」有完整说明。
- Ctrl+B切换侧栏，Ctrl+D切换详情，Alt+左右后退/前进；视图菜单切换深浅主题。
- 主题采用约280ms柔和颜色过渡，按钮轻压回弹；尊重Windows减少动画设置。卡片不再常驻「引用」角标，鼠标移到文件或应用上会在底栏显示引用/管理模式及真实路径，移开恢复操作反馈。
- 缩略图只为可见卡片后台读取，缓存有界，不写Library缩略图磁盘库；应用用Windows原生图标。视频/文档依赖系统安装的预览处理器和编解码器，不可用时显示相应类型图标；不播放视频、不自动启动应用、不对扫描文件全量读取内容。

## 管理存储与版本

「规范存储」与虚拟分类分开。先在设置中选择目录，之后对单个文件显式「纳入Library管理」，确认源/目标路径后才移动。位置采用 `Files/<FileId>/<原文件名>`，分类改名不会移动文件。

内容版本**没有默认存储目录**：先在设置选择一个与扫描根、数据库和规范存储都分离的版本目录。选文件→保存当前版本→核对源路径/大小/目标→确认。完整读取只发生在这种明确操作中；普通索引不读内容、不全量Hash。

历史→内容版本：可重建原位置缺失文件，或另存为全新独立文件。目标存在则拒绝覆盖；另存为产生新FileId，成功后追加恢复快照。版本对象按SHA-256去重；复用前重新校验。

元数据快照只记录采集时观察到的索引、位置和分类标签等状态，不是完整文件备份。可手动采集和比较；自动元数据快照默认关闭，可在设置开启。它不自动保存文件内容。

Ctrl+Z仅撤销本会话最近一次成功的**单文件位置操作**（重命名/移动/纳管），先预览并确认，身份或原位置占用异常时拒绝。没有Redo；目录、回收站还原、整个快照/文件系统回滚不在此入口。回收站文件请从Windows回收站还原；已保存内容可从内容版本恢复。

维护仅在预览确认后删除版本目录内超过7天、无任何记录引用的孤儿/临时产物。保存的版本和快照永久保留，不自动清理。已配置版本库不提供静默换库或迁移。

## 数据与边界

默认数据库：`%LOCALAPPDATA%\Library\library.db`。**其中的分类、标签、历史和版本记录不能靠重扫重建，不要删除。** 备份时关闭应用，备份数据库及独立版本目录；原文件另行备份。交付包不附带任何用户数据库、个人文件或配置。

无法获得完整原生文件身份的卷仍能索引和打开；修改与位置撤销保守拒绝。暂不提供多窗口/多进程操作互斥、完整快照回滚、自动内容采集、版本库迁移、AI、云同步或内容搜索。网络/非NTFS、磁盘满、强杀、多显示器/高对比度等异常环境未全部验收。当前验收以Win11实机及隔离NTFS测试文件为准。

开发验证：`--stress=50000 --diagnostics`始终使用示例数据；`--roots="D:\TestRoot" --db="D:\TestDb\library.db"`可限定真实验证；显式空`--roots=`不会回退到个人目录。`--no-index`只打开已有索引。
